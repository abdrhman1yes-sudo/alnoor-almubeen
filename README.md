# Alnoor AlMubeen Web App

تطبيق ويب إسلامي احترافي يجمع بين:
- القرآن الكريم
- الأحاديث المختارة
- الأذكار اليومية
- مساعد ذكي بـ Gemini
- تنقل واضح وسلس بين الأقسام
- تصميم حديث ومتجاوب

## التقنيات
- React + TypeScript
- Vite
- React Router
- Lucide Icons

## التشغيل
1. Install dependencies:
   npm install
2. Copy environment file:
   cp .env.example .env
3. Add your Gemini API key:
   VITE_GEMINI_API_KEY=your_key_here
4. Start the app:
   npm run dev

## البناء للنشر
npm run build

## ملاحظات
- إذا لم تضف مفتاح Gemini، سيعمل المساعد في وضع تجريبي.
- المشروع مصمم ليكون واجهة احترافية وتمكنك من توسيعه بسهولة.
